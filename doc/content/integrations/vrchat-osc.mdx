# VRChat OSC

Stream EEG band powers to VRChat via UDP OSC. Enable with `--osc` or from the dashboard.

```bash
pieeg-server --osc                                          # defaults
pieeg-server --osc --osc-mode chatbox --osc-interval 0.5    # chatbox only, 2 Hz
```

## Modes

| Mode | Output |
|------|--------|
| `chatbox` | Band powers as text in VRChat chatbox |
| `parameters` | Avatar parameter floats (normalized 0–1) |
| `both` | Chatbox + avatar parameters (default) |

## Configuration

| Flag | Default | Description |
|------|---------|-------------|
| `--osc-host` | `127.0.0.1` | VRChat receiver address |
| `--osc-port` | `9000` | VRChat OSC port |
| `--osc-mode` | `both` | `chatbox`, `parameters`, or `both` |
| `--osc-interval` | `0.25` | Update rate in seconds |

## WebSocket Control

```json
{"cmd": "osc_start"}
{"cmd": "osc_stop"}
{"cmd": "osc_configure", "host": "127.0.0.1", "port": 9000, "mode": "both", "interval": 0.25}
{"cmd": "osc_status"}
```

**Per-region streaming:**
```json
{"cmd": "osc_configure", "groups": [
  {"name": "Frontal", "channels": [0, 1]},
  {"name": "Occipital", "channels": [6, 7]}
]}
```

## Standard Mode (Global Band Powers)

By default, PiEEG streams **one value per frequency band**:

| Parameter | Band | Frequency Range |
|-----------|------|-----------------|
| `EEG_Delta` | Delta | 0.5–4 Hz |
| `EEG_Theta` | Theta | 4–8 Hz |
| `EEG_Alpha` | Alpha | 8–13 Hz |
| `EEG_Beta` | Beta | 13–30 Hz |
| `EEG_Gamma` | Gamma | 30–100 Hz |

Values are normalized floats (0–1) using a rolling 5-minute maximum.

The bridge uses either:
- All-channel average (`channel: "avg"`, default)
- Single selected channel (`channel: 0-15`)

## Region-Aware Mode (Per-Region Band Powers)

Stream **separate band powers for each brain region** by configuring channel groups. This enables spatial awareness in your avatar — different visuals for different brain areas.

### Configuration

Via WebSocket:
```json
{"cmd": "osc_configure", "groups": [
  {"name": "Frontal", "channels": [0, 1]},
  {"name": "Temporal", "channels": [2, 3]},
  {"name": "Parietal", "channels": [4, 5]},
  {"name": "Occipital", "channels": [6, 7]}
]}
```

Or via the dashboard:
1. OSC config panel → **"Configure Regions"**
2. Define groups: name + select channels
3. **Save** → server emits per-region parameters

### Avatar Parameters

With regions configured, the bridge emits parameters for **each region × each band**:

- `/avatar/parameters/EEG_Frontal_Alpha`
- `/avatar/parameters/EEG_Frontal_Beta`
- `/avatar/parameters/EEG_Frontal_Theta`
- `/avatar/parameters/EEG_Frontal_Gamma`
- `/avatar/parameters/EEG_Frontal_Delta`
- `/avatar/parameters/EEG_Occipital_Alpha`
- ... *(5 bands × N regions parameters total)*

### VRChat Avatar Setup

Add float parameters matching your region names:

1. VRChat Creator Companion → Parameters
2. Add float parameter: `EEG_Frontal_Alpha` (default 0, range 0–1)
3. Repeat for each region × band combination you want to use
4. Wire parameters to animators, shaders, particle effects, etc.

### Use Cases

| Mode | Example |
|------|---------|
| **Standard (global)** | Avatar glows based on overall alpha level (calm/focus) |
| **Region-aware** | Frontal alpha → forehead glow, occipital beta → eye particles, temporal theta → ear effects |

### Notes

- Regions may overlap (same channel can belong to multiple groups)
- Region names are sanitized (alphanumerics + underscore only: `Frontal Left` → `Frontal_Left`)
- Each region has independent rolling normalization
- Standard mode parameters are **not** emitted when regions are configured
